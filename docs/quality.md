# Quality gates and security triage

PR CI runs Python/SQLite tests, PostgreSQL migration/startup, container health, and Browser E2E. Browser tests exercise 390px through desktop layouts, actual recording controls, finalization/reconnection, authentication, and assistant sending. No whole-suite retry is configured. Failed browser runs retain synthetic-page HTML, screenshot, and error output for diagnosis; coverage XML is retained on every run.

Coverage includes all `server` Python modules, with no file exclusions. The measured starting line coverage is 60%; CI requires 58% to allow small line-count variation while preventing large regressions. This is an initial floor, not a target: new domain changes should improve their behavior coverage. Real external providers, startup composition, and exceptional cleanup paths account for much of the uncovered code; synthetic ASR evaluation does not establish real-model accuracy. Raising the floor requires a measured green run.

The former monolithic regression suite is split into authentication, security, history/storage, ASR, configuration, and UI contract modules. The test suite uses the installed Argon2 implementation rather than replacing a global import with a fake. Remaining source-based UI contract checks supplement browser behavior tests and should be replaced as controllers are extracted in #72. Seeded malformed WebSocket tests exercise 500 numeric/type combinations plus oversized and invalid base64. Disposable SQLite and PostgreSQL CI databases exercise upgrade/downgrade/upgrade; production downgrade safety is a separate operator exercise.

Mypy initially gates the protocol converters, transcription text processing, and public error envelopes (`mypy.ini`). Imported legacy modules are not checked transitively yet. Add extracted modules to this explicit list as #71 progresses. ShellCheck fails on errors; warnings remain a staged cleanup task. Run `python -m mypy` after installing mypy 2.3.1 and `python -m coverage run -m unittest discover -s tests` followed by `python -m coverage report` after installing coverage 7.16.0.

Security runs on PRs, main pushes, and weekly. Pip-audit fails on known dependency advisories; CodeQL records Python/JavaScript findings in GitHub code scanning. Trivy fails on fixable HIGH/CRITICAL container vulnerabilities; unfixed findings still require operator tracking before public deployment. The repository maintainer owns weekly scan triage, tool/action updates, and advisory response. Review failed scans before merging; fix affected locked versions and rerun the full suite. Any suppression must be narrowly scoped, documented with advisory ID, rationale, owner, and expiry in a reviewed PR. Do not disable a job or add a blanket continue-on-error to obtain a green build.

Use synthetic data only in artifacts. The deployment operator owns production load testing and provider latency budgets. CI regression tests do not certify production capacity.

PostgreSQL CI also submits 60 quota requests from six independent processes against a budget of 20 and requires exactly 20 accepted requests. Set `QUOTA_TEST_DB_URL` to a migrated disposable PostgreSQL instance to run it locally. It is skipped without that explicit target and cleans only its uniquely named bucket. This is a bounded contention regression, not an end-to-end recording throughput benchmark.
