# 録音中の会議パネル幅の調整

会議画面の文字起こし／会議アシスタント境界は、録音中にもドラッグまたは矢印キーで変更できます。履歴欄は既存の展開・収納操作を維持します。

従来は1600px以上のCSSがアシスタント幅を380pxへ固定していたため、操作で設定したCSS変数が反映されませんでした。また、画面縮小時に実際の表示幅を次の希望幅として使っていたため、元の大画面へ戻っても幅が戻りませんでした。

固定幅の上書きを除去し、ユーザーが選んだ希望幅と画面寸法に収まる表示幅を分けます。希望幅はlocalStorageに保存し、画面リサイズ時には同じ希望幅から表示幅を再計算します。録音状態・文字起こし更新・高精度改訂・再接続はこの設定を書き換えません。

回帰テスト `tests/browser/ui.e2e.mjs` は合成録音で、Whisper/Qwen双方の録音中に1920pxの画面で実マウスドラッグ、キーボード操作、タッチドラッグ取消を検証します。速報・高精度改訂・再接続、390pxから1440pxへの復帰、停止・再開後も希望幅を保持することを確認します。再開テストの未保存内容確認はテスト内だけで応答し、停止完了を待ってから再開します。

対象だけを実行するには、Chromeのパスを `CHROME_BIN` に指定し、`DIVIDER_REPRO_ONLY=1 node tests/browser/ui.e2e.mjs` を実行します。実マイクと既存Dockerは使いません。
