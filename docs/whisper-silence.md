# Whisperの無音時の誤認識抑制

Whisperは無音や雑音から「はい」「ご視聴ありがとうございました」などを生成することがあります。OpenWebUIなどが文字列だけを返す場合、`no_speech_prob`や`avg_logprob`は利用できません。

Whisperの速報と共通HTTPアダプターで音声を判定します。ライブの高精度認識、停止時の残り区間、言語脱落時の再認識、保存済み音声の手動再認識もこのアダプターを通ります。Qwenの速報・高精度・停止末尾・手動再認識にも同じPCM入力判定を適用します。自動言語のストリーミング速報は、受信時点の保存済み音声に活動がある場合にだけ表示します。QwenはWhisperの応答信頼度判定を使いません。

16kHz・モノラル・16bit PCM WAVでは20msごとのDCオフセットを除き、既存のRMS閾値0.003（約−50dBFS）を使います。閾値を超える区間がなければモデルを呼びません。さらに、活動フレームが500ms以上あり、その全てのRMSが0.01未満、ゼロ交差率が0.35超、RMSの変動係数が0.1未満の場合だけ、静かな定常広帯域雑音として抑制します。一つでも声らしい低いゼロ交差率や変化する音量があれば保持します。短い相槌に最低発話時間や発話割合を要求しません。

認識へ渡すWAVは発話の前後に各300msを残し、それより外の長い低音量区間を削ります。元のPCMや音声ファイルは変更せず、モデルが返す時刻は元の音声の位置へ戻します。文字列だけで締めの言葉を削除しません。

モデルから信頼度が返る場合は、全セグメントが`no_speech_prob > 0.6`かつ`avg_logprob <= -1.0`のときに無音として扱います。高い信頼度の発話や、発話を含む混合セグメントは残します。無音と判定された応答を、文章を増やすために再認識しません。この基準は[Whisperの無音判定と信頼度による除外解除](https://github.com/openai/whisper/blob/main/whisper/transcribe.py)を参考にしています。

手動再認識では、音声や信頼度から無音と判定できた行を空にできます。元の文章は`originalText`と`.original.jsonl`に残し、他の発話は通常どおり認識します。無音の証拠がない単なる空応答は、従来どおりエラーとして原文を保持します。

これはニューラルVADではなく保守的な信号判定です。閾値より小さい声、一定の低音量の囁き、音楽、非定常雑音、短い雑音などを完全には区別できません。対象外の圧縮形式・ステレオ・別サンプルレート・不明なWAVは無音と推測せず、従来どおりモデルへ渡します。対応するメタデータがなければ応答側の無音判定もできません。実際のマイク・部屋の雑音・話者による精度は個別に確認してください。

回帰テストでは合成無音、微小雑音、DCオフセット、短い小声、弱い語尾、長い無音からの復帰、高精度区間、停止時の残り、手動再認識を検証します。合成波形と合成音声は実会議の精度評価の代わりにはなりません。
