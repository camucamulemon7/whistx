# 会議の翻訳

録音操作の下にある「翻訳」をチェックすると翻訳タブが表示されます。タブ内で翻訳先を選ぶと、左に原文、右に訳文が表示されます。日本語・英語・中国語（簡体字）・韓国語・スペイン語・フランス語・ドイツ語に対応します。

チェックが入っていれば、文字起こしや要約など別のタブを表示している間も翻訳します。翻訳タブを開く操作は、処理の開始条件ではありません。

高精度の確定通知を受けた次のイベントループで翻訳を開始します。翻訳中に届いた新しい確定通知はまとめ、現在の翻訳が終わり次第処理します。連続する通知で開始を先延ばしにしません。

翻訳モデルの推論処理や生成時間は表示までの待ち時間に含まれます。翻訳には即答するモデルや推論を無効にした接続が適しています。`MEETING_TRANSLATION_MODEL` に同じ生成APIで利用できる翻訳用モデルIDを指定すると、要約・質問用の `SUMMARY_MODEL` を維持して翻訳だけを分けられます。未指定時は従来どおり `SUMMARY_MODEL` を使います。API接続先とキーは共通です。モデルの推論無効化に対応するかは実際のプロバイダーで確認してください。

ログインと、管理者設定の要約モデル接続が必要です。翻訳にもこの接続を使います。翻訳はASRとは別の処理で、高精度の確定イベントを受けて新しい区間を翻訳します。録音終了時は速報を保持した区間も対象にします。高精度の二段階認識がないバックエンドでは終了後に翻訳します。翻訳をオフにすると進行中の表示リクエストを中止します。

Whisper のライブ文字起こしは、録音中の認識途中の文字を「認識中」として表示します。この途中表示は翻訳や保存済み文字起こしには使いません。Whisper も高精度の再認識を自動実行し、その確定結果から録音中に翻訳します。停止時は残りの区間を再認識して翻訳します。高精度処理を管理者が無効にした場合や互換性のためのチャンク録音では、終了通知の後に翻訳します。入力言語は音声認識側の設定、翻訳先は翻訳タブの設定です。Whisper の音声翻訳 API や `task=translate` は使いません。翻訳用の要約モデルが未設定の場合は、その理由を画面に表示します。

英語音声を使う場合は「音声の言語」を「英語」または「自動検出」にしてください。「日本語」を指定すると、Whisper 自体が英文を日本語で返す場合があります。翻訳のチェックや翻訳先の変更は、この入力言語を変更しません。高精度認識が短い英文を別言語に置き換えたと検出できる区間は、速報の英文を保持し、訳文は別の列に表示します。

訳文は原文・区間ID・言語別に保存します。同じ原文は再翻訳せず、原文が変更された区間は再生成します。会議を履歴に保存すると翻訳データも引き継がれます。別の会議や言語に切り替えた際に、前の会議の応答を表示しません。

Whisper と Qwen の高精度認識は、既定で有効です（`ASR_HIGH_ACCURACY_ENABLED=1`）。新しい録音では通常30秒分の音声ごとに実行します（`ASR_HIGH_ACCURACY_WINDOW_SECONDS=30`）。10秒以上たまり、末尾の無音を検出した場合は早めに実行します。同じ音声認識モデルを長い区間で再実行するため、精度の改善を保証するものではありません。モデルの処理時間と待ち行列により、画面への反映は音声の区切りより遅れる場合があります。既存の録音を再開する場合は、その録音に保存された区切り時間と高精度設定を維持します。

「スクリーンショットを保存（画面共有時）」も通常画面から切り替えられます。詳細設定のサイドパネルは廃止しました。
