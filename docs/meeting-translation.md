# 会議の翻訳

録音操作の下にある「翻訳」をチェックすると翻訳タブが表示されます。タブ内で翻訳先を選ぶと、左に原文、右に訳文が表示されます。日本語・英語・中国語（簡体字）・韓国語・スペイン語・フランス語・ドイツ語に対応します。

ログインと、管理者設定の要約モデル接続が必要です。翻訳にもこのモデルを使います。翻訳はASRとは別の処理で、高精度の確定イベントを受けて新しい区間を翻訳します。録音終了時は速報を保持した区間も対象にします。高精度の二段階認識がないバックエンドでは終了後に翻訳します。翻訳をオフにすると進行中の表示リクエストを中止します。

訳文は原文・区間ID・言語別に保存します。同じ原文は再翻訳せず、原文が変更された区間は再生成します。会議を履歴に保存すると翻訳データも引き継がれます。別の会議や言語に切り替えた際に、前の会議の応答を表示しません。

Qwenの高精度認識は、新しい録音では通常30秒分の音声ごとに実行します（`ASR_HIGH_ACCURACY_WINDOW_SECONDS=30`）。10秒以上たまり、末尾の無音を検出した場合は早めに実行します。モデルの処理時間と待ち行列により、画面への反映は音声の区切りより遅れる場合があります。既存の録音を再開する場合は、その録音に保存された区切り時間を維持します。

「スクリーンショットを保存（画面共有時）」も通常画面から切り替えられます。詳細設定のサイドパネルは廃止しました。
